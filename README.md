# CND Редактор

Закрытый сайт для фракции СМИ California NewsDay (CND) сервера AtlantWorld: редактор статей и постеров, шаблоны, персонажи со скинов Minecraft, вход по токенам с журналом входов.

Автор: **Kirill_Burnside**. © 2026, все права защищены, см. [LICENSE](LICENSE).

## Что умеет

- **Вход**: токен + игровой ник + скриншот удостоверения CND. Админ входит без удостоверения. Токен выдаётся на ник, срок задаётся в часах или днях (до 90 дней), в шапке идёт таймер до окончания.
- **Админка**: выдача токенов (личные и групповые), отзыв и продление (+42 ч, +1 д, +7 д), журнал входов с фото удостоверений и пометкой подозрительных входов, CSV, проверка работ, журнал экспортов, «Чья это работа?» по невидимой метке, настройки.
- **Редактор**: слои, текст (правка двойным кликом, обводка букв), фото (загрузка, перетаскивание, Ctrl+V), направляющие, отмена/повтор, автосохранение, корзина на 30 дней, подсказки.
- **Элементы как в Canva**: фигуры, стрелки, реплики, иконки, рамки для фото любой формы с обводкой, градиенты, диаграммы (столбцы, полосы, линия, круговая, кольцевая, прогресс), таблицы, персонажи CND, импорт SVG/PNG в общую библиотеку редакции, конструктор фигур.
- **Обработка как в Photoshop**: фильтры и коррекция фото, тени и свечение, режимы наложения, отражение, выравнивание по листу, удаление фона, увеличение качества.
- **Шаблоны**: 21 официальный, у каждого своя механика (жидкое стекло, рамки по форме, диаграммы, таблица, фильтр «сепия» в розыске и др.), свои шаблоны в общей библиотеке, поиск, сворачиваемые категории.
- **Персонажи**: скин по нику или файлом; 2D-голова, плоский персонаж, **3D-голова** и 3D-персонаж с позами и шестью схемами света, рендер в прозрачный PNG.
- **Экспорт**: PNG, JPG, WEBP, копирование в буфер, отправка в Discord. Водяной знак обязателен, 6 видов (логотип в углу, логотип + подпись, полоса, штамп, узор, по центру). У стажёров без одобрения — «ЧЕРНОВИК CND». В каждый PNG зашита невидимая метка автора.
- **Discord**: вебхук в настройках админки. Уведомления о проверке, одобрении, входах, токенах и экспортах шлёт сама база (расширение `pg_net`), ссылку вебхука видят только редакторы и админы.
- **Тёмная тема**, инструкция (кнопка «?» или F1).

## Защита от копирования

- `npm run build:protected` (так собирает GitHub Actions) запутывает код сайта и включает привязку к домену: на чужом сайте копия не запустится. Свои домены — переменная `CND_DOMAINS` через запятую.
- Исходные карты (source maps) не публикуются.
- Данные и доступ защищены на стороне базы: без токена ничего не прочитать.

## Режимы работы

- **Демо** (без настроек): данные хранятся только в браузере. Вход: токен `CND-DEMO-ADMN`, ник `Admin`.
- **Боевой** (Supabase): общие данные для всей фракции.

## Запуск с Supabase

1. Зарегистрируйтесь на [supabase.com](https://supabase.com) и создайте проект (бесплатный тариф).
2. Откройте **SQL Editor**, вставьте содержимое `supabase/schema.sql` и нажмите **Run**. После обновлений сайта запускайте файл ещё раз: он безопасно обновит функции и не тронет данные.
3. Там же выполните `select cnd_bootstrap_admin('ВашНик');` — получите первый токен главного админа.
4. В **Project Settings → API** скопируйте `Project URL` и `anon public` ключ.

## Публикация на GitHub Pages

1. Залейте проект в репозиторий на GitHub (ветка `main`).
2. Адрес и anon-ключ Supabase уже прописаны в `.github/workflows/deploy.yml`. Для другого проекта задайте секреты `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY` в **Settings → Secrets and variables → Actions**.
3. **Settings → Pages** → Source: **GitHub Actions**.
4. После каждого push сайт сам пересобирается: `https://<логин>.github.io/<репозиторий>/`.

## Программа для Windows

Папка `desktop/`: маленькая программа на Go, внутри которой лежит весь сайт. Двойной клик открывает редактор в браузере по адресу `http://127.0.0.1:47615/`, после закрытия вкладки программа сама выключается. Сборка: `desktop/build.sh` (нужны Node.js и Go).
