# CND Редактор — бета

Закрытый сайт для фракции СМИ California NewsDay (CND): редактор статей и постеров, шаблоны, персонажи со скинов Minecraft, вход по токенам на 42 часа с журналом входов.

## Что есть в бете

- **Вход**: токен + игровой ник + скриншот удостоверения CND. Токен выдаётся на конкретный ник и живёт 42 часа.
- **Админка**: выдача токенов (личные и групповые), отзыв и продление, журнал входов с фото удостоверений и пометкой подозрительных входов, выгрузка журнала в CSV, проверка работ, журнал экспортов, «Чья это работа?» по невидимой метке, настройки (режим входа, водяной знак, должности → роли).
- **Редактор**: холст с слоями, текст (правка двойным кликом), фото (загрузка, перетаскивание, Ctrl+V), фигуры, рамки для фото, направляющие по центру и краям, отмена/повтор, автосохранение.
- **Шаблоны**: 4 официальных шаблона CND, сохранение своих в общую библиотеку, поиск по названию, тегам и автору.
- **Персонажи**: скин по нику (Mojang или Ely.by) или файлом; 2D-голова, плоский персонаж, 3D-персонаж с позами и шестью схемами света, рендер в прозрачный PNG.
- **Экспорт**: PNG, JPG, WEBP в 1× / 2×, копирование в буфер обмена (PNG). Логотип CND ставится автоматически, у стажёров без одобрения — плитка «ЧЕРНОВИК CND». В каждый PNG зашита невидимая метка автора.

Следующие этапы: автоматическое чтение удостоверений, удаление фона, ИИ-корректор, импорт PSD/PDF/DOCX, GIF, сборщик журнала, Discord, статистика.

## Режимы работы

- **Демо** (без настроек): данные хранятся только в браузере. Вход: токен `CND-DEMO-ADMN`, ник `Admin`.
- **Боевой** (Supabase): общие данные для всей фракции.

## Запуск с Supabase

1. Зарегистрируйтесь на [supabase.com](https://supabase.com) и создайте проект (бесплатный тариф).
2. Откройте **SQL Editor**, вставьте содержимое `supabase/schema.sql` и нажмите **Run**.
3. Там же выполните `select cnd_bootstrap_admin('ВашНик');` — получите первый токен главного админа.
4. В **Project Settings → API** скопируйте `Project URL` и `anon public` ключ.

## Публикация на GitHub Pages

1. Залейте проект в репозиторий на GitHub (ветка `main`).
2. **Settings → Secrets and variables → Actions** → добавьте `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY`.
3. **Settings → Pages** → Source: **GitHub Actions**.
4. После каждого push сайт сам пересобирается: `https://<логин>.github.io/<репозиторий>/`.
